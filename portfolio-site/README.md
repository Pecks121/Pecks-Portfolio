# Peculiar Chisom Oranu — Portfolio

A React (Vite) single-page portfolio.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build      # outputs static files to /dist
npm run preview    # preview the production build
```

## Deploy to GitHub Pages
This repo includes a GitHub Actions workflow (.github/workflows/deploy.yml).
Push to the `main` branch, then in the repo go to Settings → Pages →
Build and deployment → Source: **GitHub Actions**. Your site publishes automatically.
